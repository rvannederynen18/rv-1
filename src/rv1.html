                          Motor FLA & protection

                          NEC 430
                          FLA from Table 430.250; conductor 125% of FLA, 75°C copper (Table 310.16); max device from Table 430.52, rounded up to the next standard size. Overload is 115–125% of nameplate per 430.32. Always confirm with the code book and local rules.

                          Voltage drop & wire size

                          Smallest copper size that meets both ampacity (75°C) and the drop target, using NEC Chapter 9, Table 8 resistance.
